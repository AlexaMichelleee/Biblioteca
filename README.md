##Descripccion 
Este proyecto consiste en una aplicación para la gestion de una biblioteca.
Permite realizar operaciones como registrar, consultar, actualizar y eliminar información. 

##instrucciones para ejecutar proyecto
1. Descargar o clonar el repositorio
2. Abrir el proyecto en Apache NetBeans
3. Ejecutar la clase principal del proyecto
4. Utilizar la interfaz gráfica para realizar las operaciones correspondientes.
